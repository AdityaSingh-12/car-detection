📌 Overview

AI Car Detection & Classification is a computer vision project designed to detect vehicles from a live camera feed and determine their vehicle type using deep learning.

The system combines:

YOLO object detection for detecting vehicles.
A custom-trained YOLO classification model for identifying vehicle types.
OpenCV for real-time camera capture and image processing.

The project is being developed as a core computer-vision component for an AI-based Smart Parking System, where vehicle classification can later be used to determine the most suitable parking slot.
